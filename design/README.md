# Design Assets & Tokens

Source of truth for Dot.'s visual language.

- **`tokens.json`** — color, spacing, typography tokens (Doto font, monochromatic).
- **`fonts/`** — aset font (Doto, lisensi terbuka).

Tokens here are the single reference for values. Jangan transkripsi tangan ke
Compose: `tokens.json` → `Color.kt` harus lewat generator kanonik. Generator itu
belum ada di repo dan dicatat sebagai risiko terbuka
[`docs/STATUS-MAP.md`](../docs/STATUS-MAP.md) §4c.
