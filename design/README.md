# Design Assets & Tokens

Source of truth for Dot.'s visual language.

- **`tokens.md`** — color, spacing, typography tokens (Doto font, monochromatic).
- **`layout.md`** — pixel-grid & dot-spacing rules (Nothing-style grid).
- **`icons/`** — exported SVG/PNG icons.

Tokens here are the single reference for the Android Compose theme in
`android/app/src/main/java/.../theme/`. Edit values here; do not hand-edit
the Compose constants.
